# Catalyst.K Raspberry Pi
## Introduction
The Raspberry Pi 3, 4, and 5 are all compatible with the Catalyst.K kit. You can use either the Creality open-source version or the official version of Klipper. 

##  General Klipper
Please refer to https://github.com/dw-0/kiauh to complete the installation. When using General Klipper, you must use the Catalyst.K Leveling included in the kit.

## K1_Series_Klipper
Please refer to https://github.com/bean22-dev/K1_Series_Klipper to complete the installation. The Catalyst.K and Catalyst.K ToolHead circuit boards on the original machine can be replaced individually. When using K1_Series_Klipper, you must use the creality Leveling board.
